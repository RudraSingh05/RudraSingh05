# 🚨 Featured Project — RescueChain

### Emergency Supply Chain Platform

A microservices-based platform designed to help users discover and reserve critical emergency supplies such as **oxygen cylinders, blood, and medicines** from nearby suppliers.

### 🧰 Tech Stack

`React` • `Node.js` • `Express.js` • `PostgreSQL` • `Prisma` • `Redis` • `Docker` • `Jenkins` • `AWS`

### ⚡ Key Highlights

- 📍 Location-based nearest supplier discovery
- 📦 Real-time inventory & reservation management
- 🔐 JWT authentication & role-based authorization
- 👥 User, Supplier & Admin architecture
- ⏳ Automated reservation expiry & inventory restoration
- 🐳 Containerized microservices using Docker
- 🌐 Nginx-powered production frontend
- ⚙️ Production-focused CI/CD pipeline
- ☁️ Cloud deployment architecture
